# Outer Wilds x Project Hail Mary Interactive Fan Chart

An interactive, canvas-rendered orbital simulation and fan chart marrying the worlds of **Outer Wilds** (Mobius Digital) and **Project Hail Mary** (Andy Weir).

## Features
- **Grand System Scale:** Hand-rendered celestial bodies and orbits filling the viewport.
- **Project Hail Mary Integration:** The Beetle (Hail Mary) orbiting and actively siphoning Astrophage from the Sun via a focused Petrova line.
- **The Interloper:** Tilted Keplerian eccentric orbit with dynamic curved dust & gas tail and glowing ice coma.
- **Interactive Signalscope Mode (S key):** Authentic Hearthian CRT overlay with real-time audio waveform visualizer and frequency tuning for isolated traveler instruments.
- **Live Planetary Weather & Physics:**
  - Hollow's Lantern volcanic eruptions (magma meteors arcing across space to Brittle Hollow).
  - Giant's Deep cyclones with rotating storm vortices.
  - Atmospheric horizon rim lighting and day/night twilight shading.
  - Parallax deep-space nebulae and twinkling starfield.
- **Curated Soundtrack:** Alternating between Andrew Prahlow's *Outer Wilds (Main Theme)* and *Amaze Amaze Amaze (Life on Erid)*.
